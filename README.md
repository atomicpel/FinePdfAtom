# FinePdfAtom

Распознавание текста **без интернета** для **Astra Linux SE 1.6, 1.7, 1.8** и других Linux x86_64 с glibc ≥ 2.17.

Сканы, фото документов, многостраничные PDF и TIFF, область экрана, картинка из буфера обмена → **документ Word/LibreOffice с сохранённым оформлением**, таблицы в **Excel**, **PDF с поиском по тексту** (в том числе компактный MRC), HTML, TXT.

## Возможности

| | |
|---|---|
| **Источники** | файлы JPG/PNG/TIFF/BMP/WEBP/PDF (перетаскиванием или папкой целиком), сканер через SANE, область экрана, буфер обмена |
| **Движок** | Tesseract 5.5 (нейросеть LSTM), модели высшей точности `tessdata_best`: русский, английский, украинский; можно добавить любой язык файлом `.traineddata` |
| **Подготовка** | выпрямление фото листа по краям страницы (перспектива), автоповорот 90°/180°/270°, исправление перекоса, удаление теней, фона и просвечивающего текста, инверсия светлого текста на тёмном фоне, подбор масштаба под размер шрифта |
| **Анализ страницы** | собственная разметка: колонки и порядок чтения, таблицы с линовкой (включая объединённые ячейки), рисунки, заголовки, абзацы, списки; зоны видны поверх страницы с номерами порядка чтения |
| **Оформление** | кегль, жирный, курсив, выравнивание (влево/по центру/вправо/по ширине), красная строка, интервалы, многоколоночная вёрстка |
| **Орфография** | словари Hunspell (русский, английский, украинский): слова не из словаря подчёркиваются, по правому щелчку — варианты замены и «Добавить в словарь»; явные ошибки распознавания («иноормации» → «информации») исправляются сами; латинские буквы-двойники в русских словах заменяются |
| **Проверка** | сомнительные слова подсвечиваются; щелчок по слову в тексте показывает его на картинке, и наоборот; F3 — к следующему; ручные правки попадают во все форматы, включая текстовый слой PDF |
| **Результат** | DOCX и ODT в двух режимах — «редактируемая копия» (оформление, колонки, таблицы, рисунки) и «простой текст»; XLSX (каждая таблица — отдельный лист, числа становятся числами); HTML; PDF с текстовым слоем — цветной, компактный MRC (в 3–8 раз меньше), серый, чёрно-белый; TXT; копирование в буфер (таблицы — через табуляцию, вставляются в Excel/Calc) |
| **Скорость** | несколько страниц распознаются параллельно; движок использует AVX2/AVX-512, если процессор их поддерживает |
| **Пакетный режим** | папка → отдельный документ на каждый файл (в окне и из командной строки) |
| **Офлайн** | один `.deb` содержит всё: свой Python 3.11, Qt 5.15, Tesseract, модели. Репозитории Astra не нужны |

Идеи взяты из лучших открытых проектов: **gImageReader** (текст рядом с изображением, области распознавания, сканер), **OCRmyPDF** (конвейер подготовки, PDF с текстовым слоем поверх исходной страницы, пропуск страниц с готовым текстом), **NormCap** (распознавание области экрана сразу в буфер обмена).

## Установка (без интернета)

Скопируйте `finepdfatom_1.1.0_amd64.deb` на компьютер и выполните:

```bash
sudo dpkg -i finepdfatom_1.1.0_amd64.deb
finepdfatom --check        # проверка: движок, языки, библиотеки окна, сканер, ЗПС
```

Программа появится в меню «Пуск» → «Офис»: **FinePdfAtom** и **Текст с экрана**.

**ЗПС (замкнутая программная среда).** Если на машине включён контроль цифровой подписи исполняемых файлов, неподписанные файлы пакета не запустятся. `finepdfatom --check` показывает состояние ЗПС.

**Сканер.** Нужна утилита `scanimage` из пакета `sane-utils` (есть на установочном диске Astra) и драйвер сканера. Проверка: `scanimage -L`.

**Если окно не открывается**, `finepdfatom --check` перечислит недостающие системные библиотеки X11 (обычно они уже есть в Fly). Их можно поставить с диска Astra: `libxcb-icccm4 libxcb-image0 libxcb-keysyms1 libxcb-randr0 libxcb-render-util0 libxcb-xinerama0 libxcb-xkb1 libxkbcommon-x11-0`.

Удаление: `sudo dpkg -r finepdfatom`.

## Работа

1. Перетащите файлы в окно (или «Открыть», «Сканер», «Экран», «Буфер») — распознавание начнётся само.
2. Проверьте подсвеченные слова (F3), поправьте текст.
3. «Сохранить» → PDF / DOCX / ODT / TXT.

**Только часть страницы:** кнопка «Область» → обведите фрагмент мышью.

**Текст с экрана по горячей клавише:** назначьте в настройках горячих клавиш рабочего стола команду

```bash
finepdfatom --screen
```

Выделите область — текст сразу окажется в буфере обмена.

### Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+O | Открыть файлы |
| Ctrl+R | Распознать |
| Ctrl+S | Сохранить как PDF |
| Ctrl+Shift+E | Область экрана |
| Ctrl+Shift+V / Ctrl+V | Картинка из буфера |
| Ctrl+Shift+S | Сканер |
| Ctrl+Shift+C | Копировать весь текст |
| F3 | Следующее сомнительное слово |
| Ctrl+колесо, Ctrl+0 | Масштаб, по размеру окна |

## Командная строка

```bash
# один документ из нескольких файлов
finepdfatom ocr скан1.jpg скан2.jpg договор.pdf -o договор_с_текстом.pdf

# папка целиком: на каждый файл свой PDF, DOCX и Excel
finepdfatom ocr ~/Сканы --outdir ~/Готово --format pdf,docx,xlsx

# компактный PDF (MRC)
finepdfatom ocr скан.pdf -o скан_малый.pdf --pdf-quality mrc

# фото, только русский, строки склеить в абзацы
finepdfatom ocr фото.jpg -o текст.txt -l rus --mode photo --join-lines

finepdfatom ocr --help
```

## Языки

В комплекте: русский, английский, украинский (+ модель ориентации страниц). Другие языки — файлы из [tessdata_best](https://github.com/tesseract-ocr/tessdata_best): «Настройки» → «Добавить язык», или положите `.traineddata` в `~/.local/share/finepdfatom/tessdata/`.

## Сборка пакета

На любом Linux x86_64 с интернетом (Ubuntu 22.04+, Debian 12, Astra 1.8):

```bash
sudo apt install git cmake make python3 python3-pip binutils dpkg-dev curl
./packaging/build.sh          # → dist/finepdfatom_<версия>_amd64.deb
```

Скрипт собирает Tesseract 5.5.4 и Leptonica компилятором zig под **glibc 2.17**, берёт колёса Python стандарта manylinux2014 и в конце проверяет, что ни один файл пакета не требует glibc новее 2.17 (в Astra 1.6 — glibc 2.24).

## Устройство

```
finepdfatom/
  tess.py         привязка к libtesseract (C API, ctypes): слова, строки, блоки, кегль, отмена
  preprocess.py   перспектива фото, поворот, перекос, фон, масштаб, инверсия
  layout.py       анализ макета: таблицы по линовке, рисунки, колонки и порядок чтения (XY-cut)
  formatting.py   абзацы, кегль, жирный/курсив, выравнивание, заголовки
  postfix.py      кириллица/латиница, маркеры списков, мусор у рамок
  spell.py        орфография (Hunspell через spylls), исправление явных ошибок
  ocr.py          пул движков по потокам, страница → результат
  textlayout.py   текст для редактора + карта «символ ↔ слово», перенос правок в слова
  docmodel.py     логическая модель документа (абзацы, таблицы, рисунки, колонки)
  richexport.py   DOCX, ODT, HTML, XLSX с оформлением
  export.py       PDF с текстовым слоем (в т.ч. MRC), диспетчер форматов
  sources.py      файлы, PDF, TIFF, сканер (scanimage)
  cli.py          командная строка
  gui/            интерфейс Qt: окно, просмотр, редактор, выделение экрана, диалоги
packaging/        сборка .deb
tests/            генератор тестовых сканов, замер точности, проверки интерфейса
```

Проверка анализа макета (колонки, таблица с объединённой ячейкой, рисунок, заголовки) и фото листа:

```bash
python tests/make_layout_sample.py samples_layout && python tests/layout_check.py samples_layout
python tests/show_layout.py samples_layout/layout.png layout.png   # картинка с найденными зонами
```

Проверка точности на синтетических «сканах» (перекос, перевёрнутая страница, фото с тенью, тёмная тема, снимок экрана 13 px):

```bash
python tests/make_samples.py samples && python tests/bench.py samples
```

## Лицензия

AGPL-3.0-or-later (из-за PyMuPDF). Лицензии компонентов — в `/opt/finepdfatom/LICENSES`.
